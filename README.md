
# Homework 7 – Process Scheduling Simulation

This program implements two CPU scheduling algorithms in C:

- First Come First Served (FCFS)
- Shortest Job First (SJF) – Non-preemptive

## Features

- Process arrival and burst time input
- Gantt charts for both algorithms
- Waiting, turnaround, and response times
- Average scheduling metrics
- CPU idle time handling

## Compilation

```bash
gcc *.c -o s
```

## Execution

```bash
./s
```

Enter the number of processes, then the arrival and burst times for each process.
